# Celebrare Photo Gallery

A responsive photo gallery application built with **React, Vite, and Tailwind CSS** as part of the Celebrare Web Developer Internship pre-screening assignment.

Explore photos from the Picsum Photos API, search for photographers by name, and save your favorite photos. Favorites are persisted in the browser using `localStorage`.

## ✨ Features

- **Photo Gallery:** Fetches and displays 30 photos from the Picsum Photos API.
- **Responsive Design:** Displays 1 column on mobile, 2 columns on tablet, and 4 columns on desktop.
- **Real-Time Search:** Filter photos by photographer name as you type.
- **Favorites:** Add or remove photos from your favorites list.
- **Persistent Favorites:** Favorites remain saved after refreshing the page using `localStorage`.
- **Loading State:** Displays an animated spinner while photos are being fetched.
- **Error Handling:** Displays an error message if the API request fails.
- **Interactive UI:** Includes smooth hover effects, image zoom, and card animations.

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- Tailwind CSS
- Picsum Photos API
- React Hooks: `useState`, `useEffect`, `useReducer`, `useCallback`, and `useMemo`
- Browser `localStorage`
